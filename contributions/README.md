# Notebook theo nội dung

Các file ở đây chỉ có đề mục, mô tả ngắn và code TODO; chưa có import, đọc dữ liệu hoặc lời giải.
Không có tên hoặc phân công thành viên. Khi triển khai, có thể dùng dữ liệu chung qua `src/lab2_data.py`.

| File | Nội dung |
|---|---|
| `01_eda.ipynb` | Khám phá dữ liệu |
| `02_adf_differencing.ipynb` | Kiểm định ADF và sai phân |
| `03_acf_pacf.ipynb` | ACF/PACF và đề xuất cấu hình |
| `04_arima.ipynb` | Fit ARIMA, hội tụ và phần dư |
| `05_forecast_evaluation.ipynb` | Dự báo và đánh giá |
| `06_sarima.ipynb` | SARIMA Dataset 2 |

Xem [quy trình và phụ thuộc](../CONTRIBUTING.md) trước khi bắt đầu.
