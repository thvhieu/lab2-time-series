# Khu vực làm việc thành viên

Notebook tổng hợp tại repo root do leader tích hợp. Thành viên tạo file phần riêng ở đây
theo bảng trong [CONTRIBUTING.md](../CONTRIBUTING.md), không sửa chồng lên notebook chung.

| Tên file | Nội dung |
|---|---|
| `tv02_adf.ipynb`, `tv02_notes.md` | ADF và sai phân hai dataset |
| `tv03_acf_pacf.ipynb`, `tv03_notes.md` | ACF/PACF, đề xuất tham số |
| `tv04_arima.ipynb`, `tv04_notes.md` | Fit ARIMA và kiểm tra phần dư |
| `tv05_evaluation.ipynb`, `tv05_notes.md` | Forecast, metrics, so sánh |
| `tv06_sarima.ipynb`, `tv06_notes.md` | SARIMA Dataset 2 |

Các tên trên là quy ước bàn giao, không phải file đã được tạo.
Đọc dữ liệu từ `../data/` khi notebook chạy tại thư mục này; không sao chép thêm CSV.
